# Independent phone scan collection

Take photos through the actual SNAPTURE camera. Use the exported or analyzed
guide crop if recording a box for that crop. Record box corners as normalized
coordinates relative to the image referenced in the CSV. Leave boxes blank
when there is no supported item and note the expected outcome.

1. Start with genuine HDPE #2 bottles and jugs, PETE #1 bottle look-alikes,
   whole or broken hard coconut shell versus husk, and verified unfinished solid
   wood versus painted wood, plywood or MDF. Record the resin marking or known
   treatment history as evidence. Avoid using hazardous residues to stage photos.
2. Add supported cardboard, paper and fabric under varied lighting and
   backgrounds. Include paper held by a small hand, worn cloth versus bedding,
   plain paper versus laminated paper, and composites with known principal material.
3. Capture deliberate review cases: empty frame, hand only, multiple items,
   crops that cut off the item, and unsupported objects. A supported item remains
   a supported item if a background object is also visible.
4. Assign a unique physical-item ID. Keep related images and capture sessions
   together in one split so repeated views cannot leak.
   Keep the final test apart from training and cutoff tuning.
5. Keep captures private by default. Use consent for identifiable photos or
   leave personal details and faces outside the image. Treat unclear labels as
   review cases until evidence supports a decision.

Use `reference_template.csv` and place local images under `captures/`.
An initial pilot can expose missing variations. Automatic acceptance requires
the separate published evaluation protocol and enough independent test cases.
