# BEGIN T2

Set-Location 'C:\Users\Jude\Desktop\SNAPTURE_SYSTEM-NewFEATURES\SNAPTURE_ANDROID'
if (-not (Get-Command npm.cmd -ErrorAction SilentlyContinue)) {
    $snaptureNode = Join-Path (Split-Path -Parent (Get-Location).Path) '.tools\node-setup-v22.23.5\node-v22.23.5-win-x64'
    if (-not (Test-Path -LiteralPath (Join-Path $snaptureNode 'npm.cmd'))) {
        throw 'Node.js and npm were not found. Install Node.js or restore the portable Node folder in .tools.'
    }
    $env:Path = "$snaptureNode;$env:Path"
}
$snaptureMetroRunning = $false
try {
    $snaptureMetro = Invoke-WebRequest 'http://127.0.0.1:8081/status' -UseBasicParsing -TimeoutSec 3
    $snaptureMetroRunning = $snaptureMetro.StatusCode -eq 200 -and [Text.Encoding]::UTF8.GetString($snaptureMetro.RawContentStream.ToArray()).Trim() -eq 'packager-status:running'
} catch {}
if ($snaptureMetroRunning) { Write-Output 'Metro is already running on port 8081.' } else { npm.cmd start }

# END T2

If this command starts Metro, leave the terminal running on port 8081. An installed release app does not need Metro.

WIRELESS - MANUAL CONNECTION IF AUTOMATIC DISCOVERY HAS NOT CONNECTED

Use "IP address & Port" from the MAIN Wireless debugging screen, not the port
inside the pairing-code dialog. Read the CURRENT value from your phone.

# BEGIN WIRELESS_CONNECT
Set-Location 'C:\Users\Jude\Desktop\SNAPTURE_SYSTEM-NewFEATURES'
$adb = Join-Path $env:LOCALAPPDATA 'Android\Sdk\platform-tools\adb.exe'
$phoneAddress = Read-Host 'Connection IP:port from the MAIN Wireless debugging screen'
& $adb connect $phoneAddress
if ($LASTEXITCODE -ne 0) { throw 'Wireless connection failed. Check the phone connection address and Wi-Fi.' }
& $adb -s $phoneAddress get-state
if ($LASTEXITCODE -ne 0) { throw 'Phone is not connected at that address. Recheck its current MAIN-screen IP:port before continuing.' }
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\SNAPTURE_ANDROID\reconnect_phone.ps1 -Serial $phoneAddress -DebugBuild
# END WIRELESS_CONNECT

This restores API port 8000 and Metro port 8081, then opens the installed app.
Keep Wireless debugging enabled. Use the phone's current connection address
each time; its port may change. Your Android API_BASE_URL stays unchanged.

WIRELESS - FIRST-TIME PAIRING ONLY (ANDROID 11 OR NEWER)

Skip this when the phone is already paired with this PC. On the phone choose
Wireless debugging > Pair device with pairing code, then run this block:

# BEGIN WIRELESS_PAIR
Set-Location 'C:\Users\Jude\Desktop\SNAPTURE_SYSTEM-NewFEATURES'
$adb = Join-Path $env:LOCALAPPDATA 'Android\Sdk\platform-tools\adb.exe'
$pairingAddress = Read-Host 'Pairing IP:port shown in the phone pairing-code dialog'
& $adb pair $pairingAddress
if ($LASTEXITCODE -ne 0) { throw 'Pairing failed. Reopen the phone pairing-code dialog and retry.' }
# END WIRELESS_PAIR

Enter the pairing code directly at ADB's terminal prompt. Then return to the
phone's MAIN Wireless debugging screen and run WIRELESS_CONNECT above using
its connection IP:port. The pairing and connection ports are different.

USB ALTERNATIVE

Connect the USB data cable, unlock the phone, enable USB debugging and accept
the authorization prompt. The helper restores forwarding and opens the existing
SNAPTURE installation. It does not install the app or clear its data.

If the helper reports "Phone connected, but SNAPTURE is not installed", the
debugging connection is working but neither supported app package is present:
  com.snapture_android
  com.snapture_android.prototype
An APK must be installed separately before the helper can open the app. The
helper now checks both variants without treating an absent package as a failed
phone connection. It does not automatically install/reinstall or reset anything.

# BEGIN T3

Set-Location 'C:\Users\Jude\Desktop\SNAPTURE_SYSTEM-NewFEATURES'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\SNAPTURE_ANDROID\reconnect_phone.ps1 -DebugBuild

# END T3

For an installed release app, omit -DebugBuild; T2 is then unnecessary.
With multiple phones, append -Serial followed by the exact authorized serial.
If no app is installed, follow RUNBOOK.md section 4 for the separate build/install
procedure after setting up the JDK and Android SDK.

Manual alternative for a phone or an already-running emulator (ADB on PATH):

# BEGIN MANUAL_DEVICE
adb devices -l
$targetSerial = Read-Host 'Exact serial shown above with status device'
adb -s $targetSerial reverse tcp:8000 tcp:8000
adb -s $targetSerial reverse tcp:8081 tcp:8081
adb -s $targetSerial reverse --list
# END MANUAL_DEVICE

Then open SNAPTURE on the phone/emulator. Repeat forwarding after reconnecting.
Wireless commands are directly above. More details: RUNBOOK.md section 4, option C.
